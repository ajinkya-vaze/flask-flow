# Flask Flow: Game Spec (working title)

A calm, ad-free liquid-sort puzzle for iPhone. It plays like the genre you enjoy, but the name, art and levels are our own. There are no ads, lives, coins, purchases or tracking.

---

## 1. What I found in the reference game

- **Core loop:** tap a bottle, then tap another to pour. Each bottle has to end up holding a single color.
- **Pour rule:** you can pour only onto a matching top color or into an empty bottle, and only if there is room.
- **Tools:** Undo and Shuffle, plus coin-bought "extra bottle" (300 → 900 coins).
- **Meta systems:** lives, coins, teams, collectible cards, daily prize wheel, pop-up events (races, drills), and 100 new levels per update.
- **Monetization:** ads, coin packs ($1.99–$14.99), and bundles up to $19.99. The App Store listing shows "Loot Boxes" and third-party ad tracking.
- **Main complaints in reviews:** pop-ups, later levels that feel built to push you toward paid boosters, and boosters that are too expensive.

**Takeaway:** the puzzle is good. Almost everything people complain about is the monetization layer around it. We keep the puzzle, drop that layer, and make the helpers free.

## 2. Core gameplay

| Rule | Detail |
|---|---|
| Board | 3–14 flasks laid out in 1–2 rows (3 rows on large levels) |
| Capacity | 4 layers per flask (some later levels use 5) |
| Selecting | Tap a flask to lift it. Tap it again to put it down. |
| Pouring | Tap a target. The whole run of same-colored layers on top moves over, as much as fits. |
| Valid pour | Target is empty, **or** its top color matches and it has room |
| Leftovers | If the tapped flask fills up before the run is used up, the rest pours on to other flasks already topped with that color (the one with the most room first, never an empty flask). It counts as one move and one Undo. Can be turned off in Settings ("Pour leftovers"). |
| Invalid pour | The flask shakes with a light haptic. Nothing changes. |
| Completed flask | Full with one color. It gets a cork, a sparkle and a haptic, then it is locked. |
| Win | Every flask is either empty or completed |
| Stuck | When no valid moves remain, a gentle "No moves left" banner offers Undo or Restart. There is no fail screen and nothing to lose. |

### Free helpers (no currency)
- **Undo:** unlimited, steps back one move at a time.
- **Restart:** resets the level.
- **Extra flask:** adds one empty flask, once per level.
- **Hint:** the built-in solver highlights the next good move. Unlimited, with a short cooldown so it doesn't feel like autopilot.

## 3. Levels and difficulty

Levels are **generated by a seeded algorithm and checked by a solver**, so they are endless, the same every time, and always solvable.

1. Generator: shuffle N colors × capacity layers into N flasks, then add K empty flasks.
2. Solver (search with memoized states) proves the level can be solved and counts the minimum moves. A level that can't be solved is regenerated.
3. Difficulty score = minimum moves + branching + how often the solver hits a dead end. Levels are sorted into bands.

| Levels | Colors | Empty flasks | Twist |
|---|---|---|---|
| 1–5 | 2–3 | 2 | Tutorial with hand-pointer hints |
| 6–30 | 4–6 | 2 | Plain sorting |
| 31–80 | 6–9 | 2 | **Hidden layers:** "?" layers show their color once they are exposed |
| 81–150 | 8–11 | 2 (sometimes 1) | **Frozen flask:** unlocks after you complete any one color |
| 151+ | 10–12 | 1–2 | A mix of all twists, plus a few 5-layer levels |

- Every 10th level is a "challenge" level with a distinct background tint.
- **Daily Puzzle** (optional): one seeded level per calendar date, with a streak counter. It works offline.

## 4. Screens

1. **Home:** big "Level N" play button, Daily Puzzle card, settings gear.
2. **Game:** top bar (level, Restart, settings), flask grid, bottom bar (Undo, Hint, +Flask).
3. **Level complete:** short confetti or splash, a move count compared with the solver's best (a 1–3 star rating), and a Next button. It is not interrupted by anything.
4. **Settings:** sound, haptics, color-blind mode, reset progress.
5. **Level map** (nice-to-have): scroll back and replay old levels.

---

## 5. Look and feel (original art)

- **Style:** clean glass lab flasks on a soft gradient background, with no wizard or fantasy imagery. Liquid wobbles a little when poured.
- **Pour animation:** the lifted flask tilts over the target, a stream draws across, and the levels rise and fall (about 0.35s). Taps queue up, so fast players are never blocked.
- **Palette:** 12 distinct colors chosen to stay clear of each other. **Color-blind mode** adds a pattern or symbol to each color.
- **Audio:** soft glug and pour sounds, a chime when a flask is completed, and a short win jingle. All sounds are generated or royalty-free.
- **Haptics:** light tap on select, success haptic when a flask completes, notice haptic on win.
- Light and dark themes follow the system setting.

---

## 6. Data and privacy

- Progress (current level, stars, daily streak, settings) is stored **only on the device**.
- No network calls, analytics, ads SDK or account.
- Fully playable offline.

## 7. Platform: the one decision to make

On this Mac, **full Xcode is not installed**; only the Command Line Tools are. There are two ways to get the game onto your iPhone:

| | **A. Native iOS app (SwiftUI)** | **B. Web app installed to Home Screen (PWA)** |
|---|---|---|
| Feel | Best: smooth 120Hz animations, real haptics | Very good, but **no haptics** (iOS Safari doesn't allow them) |
| Install | Xcode (free, about 10 GB) plus your Apple ID. Plug in the iPhone and press Run. | Open a URL in Safari, then Share → Add to Home Screen |
| Catch | With a **free** Apple ID the app **expires every 7 days** and has to be re-installed from Xcode. A paid developer account ($99/yr) extends this to 1 year. | Needs a free host such as GitHub Pages. After the first load it works offline. |
| Tooling here | You'd need to install Xcode first | Works now. I can test it in the browser pane. |

**My recommendation: A (native SwiftUI)** if you're fine installing Xcode and re-running it weekly, or have a dev account. It gives the best feel, with haptics and smooth animations. Choose **B** if you want something that never expires and costs nothing to keep running.
